# images — 作品のサムネイル置き場

作品カードのサムネイルは、次の優先順で表示されます。

1. **手動画像**（一番きれい・おすすめ）
   ここに画像を置いて、`js/data.js` の作品に `image: "images/ファイル名.png"` と設定する。
   - 推奨サイズ: 横 1024px 前後、比率はだいたい 16:10（例: 1024×640）。
   - 実際の画面をスクショして使うと、内容が伝わって一番印象が良い。

2. **URLからの自動プレビュー**
   `image` を `null`（未設定）にしておくと、`liveUrl` のスクリーンショットを
   自動で表示する（thum.io の無料スクショサービスを利用）。手間ゼロだが、
   - 生成に数秒かかることがある（初回は「生成中」の画像が出る場合あり）
   - ログインが必要なサイトはログイン画面が写ってしまう
     → その作品は `preview: false` にして自動生成を止め、手動画像を使う。

3. どちらも無い場合は 💻 のプレースホルダを表示。
